6 · Accessibility contract
Targets & text
All named controls ≥ 44×44pt (searchbox raised to 44). All in-app text ≥ 12px incl. dock labels & badges. Metadata 12–13. Support Dynamic Type by scaling from these base sizes; rows reflow, never truncate meaning.
VoiceOver names / order
Bell "Open activity"; avatar "Open account and settings"; capture "Capture a new item"; dock destinations named with aria-current=page on Home; filter chips named + aria-pressed; searchbox role searchbox labeled; comp rows expose the same sale as the chart point. Reading order top→bottom.
Non-colour status
Every status pairs icon + words (sold, question, publish issue, evidence strength, framing cue). Selection = shape/label/pressed, not hue. Contrast: ink/secondary on white ≥ 4.5:1; blue #3665F3 on white for ≥14px bold / large.
Reduced Motion
Honour accessibilityReduceMotion: replace slide/rise/scale/bounce with opacity cross-fade or instant change. Composition never changes (Scout stays free-standing beside its bubble). Sheets appear without the spring.
Focus restoration
Dismissing a sheet/alert returns focus to the opening control. Board-only HOME switches reset phone scroll to top and clear transient keyboard/query/overlay. Settings hand-off returns to ONB-08 without faking a grant.
Permission / sheet dismissal
Camera alert: Allow → proceed; Don't Allow → calm recovery (Settings + library), never a dead end. Sheets dismiss via close, grabber tap, scrim tap; swipe-down where native. All escapes preserve state.
